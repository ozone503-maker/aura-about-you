# Aura About You — Vercel deployment

This folder is the complete production website for Aura About You.

## Deploy through GitHub and Vercel

1. Upload every file and folder in this package to the root of the GitHub repository.
2. In Vercel, import that GitHub repository.
3. Leave Framework Preset set to **Next.js** and leave Root Directory blank.
4. Click **Deploy**.

No environment variables are required. The soundtrack, hero video, photographs, pages, sitemap, and mobile styles are included.
